# Regras Globais do Projeto (micro-wiki)

- Sempre que houver uma alteração ou edição em códigos-fonte do projeto (seja Python, HTML, JS, CSS ou qualquer lógica da aplicação), reinicie automaticamente o projeto/servidor localmente utilizando o comando `python manage.py runserver` sem precisar pedir permissão ao usuário. Apenas execute a ação e obedeça.
- Não exija confirmação prévia para agir. Se o usuário pedir algo (como refatorar layout, alterar banco de dados), aplique a modificação e siga em frente diretamente, sem criar planos em modo de planejamento.
- Todo texto gerado ou comentários adicionados devem estar estritamente em português brasileiro (pt-BR).
- Os comentários do código devem ser curtos, diretos e explicar unicamente o que o código faz.
